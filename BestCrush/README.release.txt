BestCrush 0.2.2
===============

Installation sur un PC Windows x64 (Intel ou AMD)
-------------------------------------------------

1. Installez Dofus avec le lanceur officiel Ankama.
   https://www.dofus.com/fr/mmorpg/telecharger

2. Installez Npcap depuis son site officiel pour activer les relevés en jeu.
   https://npcap.com/#download

3. Si Microsoft Edge WebView2 Runtime est absent, installez l’Evergreen Runtime.
   https://developer.microsoft.com/microsoft-edge/webview2/#download-section

4. Faites un clic droit sur le ZIP de BestCrush et choisissez « Extraire tout ».
   Ouvrez BestCrush.exe dans le dossier extrait et gardez les autres fichiers avec lui.
   L’archive inclut .NET et le Windows App SDK.

5. Attendez la préparation du catalogue au premier lancement. Lancez Dofus en
   mode fenêtré et connectez votre personnage. Sélectionnez son serveur dans
   BestCrush si nécessaire, puis ouvrez la fiche d’un objet à l’hôtel des ventes.
   Vous pouvez retrouver le relevé dans Données, dans la catégorie de l’objet.

Données et mise à jour
----------------------

Les données BestCrush sont stockées dans %LOCALAPPDATA%\BestCrush.
Pour mettre à jour, fermez BestCrush, extrayez le nouveau ZIP et lancez son exe.

Les visuels officiels de développement sont remplacés par les visuels de repli
lorsqu’ils ne sont pas disponibles dans la distribution.

Projet et versions : https://github.com/Pagalom/DofusSharp/releases
